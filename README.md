# ABSTRACT

___________________________________________________________________________________


The hospitality industry generates large volumes of booking data through hotel reservation systems and online booking platforms. However, transforming raw booking data into meaningful business insights remains a challenge for many organizations.

This project aims to develop an AI-Based Hotel Booking Business Intelligence and Analytics System that enables users to analyze hotel booking data, generate visualizations, identify trends, and support data-driven decision-making. The system combines Business Intelligence concepts with Artificial Intelligence technologies to improve data understanding and business performance evaluation.

A hotel booking dataset containing 120,000 records was utilized. Data cleaning and preprocessing techniques were applied to improve data quality and prepare the dataset for analysis. Various visualization techniques including descriptive statistics, histograms, scatter plots, correlation analysis, and time-series analysis were implemented.

An interactive web application was developed using Streamlit, allowing users to upload datasets, perform cleaning operations, explore analytical dashboards, and generate AI-powered insights. The system also provides recommendations for dashboard design and business performance evaluation.

The results demonstrate that integrating Artificial Intelligence with Business Intelligence tools can significantly improve analytical capabilities and support strategic decision-making within the hospitality industry.

**Keywords:** Business Intelligence, Artificial Intelligence, Hotel Analytics, Data Visualization, Streamlit, Dashboard Analytics.

### **Project Description**


The hotel industry relies heavily on reservation systems and digital platforms that generate large amounts of operational data. This data contains valuable information related to customer behavior, pricing strategies, booking trends, and service performance. However, extracting meaningful insights from such data requires advanced analytical techniques and Business Intelligence solutions.

This project focuses on developing a Business Intelligence and Analytics System designed specifically for hotel booking data. The system allows users to upload datasets, clean and transform data, generate visualizations, and obtain AI-generated insights through an interactive dashboard environment.

The project combines traditional Business Intelligence methodologies with Artificial Intelligence technologies to support business users in understanding their data and making informed decisions.

# Data Primary Cleaning and Transformation

___________________________________________________________________________________


### 4**.1. Introduction**

Data quality plays a critical role in the success of Business Intelligence and analytics projects. Raw datasets often contain missing values, duplicate records, inconsistent formats, and other issues that may negatively affect analytical results. Therefore, a comprehensive data cleaning and transformation process was performed before conducting any analysis.

### 4.**2\. Data Cleaning Process**

The original dataset contained several quality issues that required correction. These issues included missing values, duplicate records, and formatting inconsistencies.

The cleaning process focused on improving data accuracy, consistency, and reliability.

**Main Cleaning Activities**

- Identifying missing values.
- Removing duplicate records.
- Standardizing data formats.
- Verifying data consistency.
- Preparing data for analysis.

### 4**.3. Missing Value Treatment**

Missing values were identified across several variables. Appropriate techniques were applied to handle these missing entries while preserving the integrity of the dataset.

Numerical variables were treated using mean value replacement, while categorical variables were assigned suitable replacement values where necessary.

### 4**.4. Duplicate Removal**

Duplicate records were identified and removed to ensure that each booking was represented only once in the final dataset.

This process improved data reliability and reduced analytical bias.

### 4**.5. Data Transformation**

Several transformation techniques were applied to prepare the dataset for analysis.

These transformations included:

- Date formatting.
- Feature engineering.
- Data type conversion.
- Variable standardization.
- Derived attribute creation.

### 4**.6. Data Quality Improvement Results**

| Metric            | Before Cleaning | After Cleaning |
| ----------------- | --------------- | -------------- |
| Records           | 128,000         | 120,000        |
| Missing Values    | 197,773         | 0              |
| Duplicate Records | 8,000           | 0              |

The cleaning process significantly improved dataset quality and prepared the data for reliable analytical activities.
